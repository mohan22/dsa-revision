# Java DSA Revision Repo

This repo is a reconstruction layer for interview prep.

Anki stays the recall trigger:
- "Do I remember the pattern?"
- "Can I recognize the problem quickly?"

This repo handles the next step:
- clean Java solutions
- solving thought process
- pattern recognition cues
- edge cases and common mistakes

## Tiering System

- `Tier 1`: Full Java solution + full revision note
- `Tier 2`: Approach + thought process + Java skeleton
- `Tier 3`: Stay in Anki only until promotion

## How To Use With Anki

1. Review cards in Anki.
2. If a card feels shaky, open the matching note here.
3. Read only these sections first:
   - `Recognition Pattern`
   - `Core Insight`
   - `Thought Process During Solving`
4. Try to rewrite the Java solution from memory.
5. Use `Edge Cases / Traps` to sanity-check your solution.

## Repository Layout

```text
problems/    Problem-level notes
topics/      Pattern summaries and reusable templates
templates/   Tier 1 and Tier 2 note formats
checklists/  Last-minute revision sheets
index.md     Master tracker
```

## First-Pass Coverage

This starter version promotes representative problems from `anki-decks.txt` into:
- Arrays and Hashing
- Sliding Window
- Stack
- Binary Search
- Dynamic Programming
- Graph / Matrix DFS
- Backtracking
- Trees / BST

## Writing Rules

- Prefer one clean Java solution over many variants.
- Keep explanations compact and interview-oriented.
- Add only the minimum comments needed inside code.
- Use topic pages for reusable patterns and problem pages for reconstruction.
