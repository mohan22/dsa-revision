# Stack and Monotonic Stack

## Recognition Cues

- Matching pairs or nested structure
- Need most recent unresolved item
- Need next greater/smaller or span information

## Core Java Tools

- Prefer `ArrayDeque<Character>` or `ArrayDeque<Integer>`
- Use `push`, `pop`, and `peek`

## Common Mistakes

- Not checking empty stack before `pop`
- Mixing value stack and index stack
- Forgetting sentinel initialization in index-based stack problems

- Valid Parentheses
- Daily Temperatures
- Largest Rectangle in Histogram
